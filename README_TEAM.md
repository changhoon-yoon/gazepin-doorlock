# GazePIN / HeadPIN 도어락 데모 — 팀원용 안내

시선(또는 고개 제스처)만으로 비밀번호를 입력하는 어깨너머 방어 도어락 프로토타입.
ESW 경진대회 준비용. 설계 근거와 보안 분석은 `doorlock_pin_design.md` 참고.

## 준비물
- Windows + 웹캠
- **Python 3.11** (mediapipe 호환 범위: 3.9~3.12. 3.13은 안 됨) — [python.org](https://www.python.org/downloads/)에서 설치

## 설치 (1회)
```
git clone <이 저장소 URL>
cd gaze-estimation
setup.bat
```
`setup.bat`이 가상환경 생성 → 패키지 설치 → 모델 가중치(4.8MB) 다운로드까지 자동으로 합니다.

## 실행
| 명령 | 데모 | 입력 방식 |
|---|---|---|
| `run_gazepin.bat` | GazePIN (보안 대표) | **눈동자** 좌/우 2지선다, 8기호 12라운드 |
| `run_headpin.bat` | HeadPIN (속도 대표) | **고개** 4방향 4지선다, 0~9 PIN 8제스처 |

데모 비밀번호는 둘 다 `1234` (다르게 하려면 `--pin 5678` 인자 수정).

### 공통 조작키
- `c` 재캘리브레이션 / `r` 입력 재시작 / `q` 종료
- HeadPIN 전용: `x` 좌우 부호 반전(좌우가 반대로 잡힐 때), **긴 깜빡임(0.5초)** = 현재 자리 취소

### 사용 흐름
1. 시작하면 캘리브레이션: 화면 중앙(GazePIN은 파란 점)을 정면으로 바라보면 자동 완료(삐 소리)
2. 키패드에서 내 숫자의 화살표(방향 배지) 확인 → 정면 복귀(무장, 테두리 초록) → 그 방향으로 흘끗/고개 돌리기
3. 자리 수만큼 반복 → 전체 일치 시 UNLOCKED, 3회 실패 시 30초 잠금

## 브랜치
- `gazepin` — 시선 2지선다 버전까지의 이력
- `headpin` — 고개 4지선다 포함 최신 (기본 브랜치, 이걸 쓰면 됨)

## 문제 해결
- **카메라가 다른 게 열림**: 데모 인자 `--source 1` 등으로 인덱스 변경
- **검은 화면**: 일부 웹캠은 DSHOW 백엔드에서 검은 프레임을 냄 — 코드 기본값(백엔드 미지정) 유지
- **HeadPIN 좌우 반대**: 실행 중 `x` 한 번
- **DOWN이 저절로 눌림**: 키패드를 읽을 때 고개가 숙여지는 것 — 화면을 눈높이에 두거나 headpin_demo.py의 `down_thr_deg` 상향
- **mediapipe 설치 실패**: Python 버전 확인 (3.11 권장)
